## 怎么用这个仓库

**自己复习时**：按目录找对应模块的笔记，笔记里都标了对应的课程章节。

**面试前**：重点看 `03_deep_learning/notes/04_损失函数与优化方法.md`（八股最密集），以及 `03_deep_learning/mindmaps/`（快速过一遍框架）。

**遇到具体报错时**：`Git常用命令-备忘.md` 里有常见错误的速查表。
