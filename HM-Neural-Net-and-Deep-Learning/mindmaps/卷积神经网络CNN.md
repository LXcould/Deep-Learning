- 卷积神经网络CNN
  - 图像概念
    - 分类
      - 1通道
      - 二值图像 0/1
      - 灰度图像 0-255
      - 索引图像 存储索引,索引对应二维矩阵行下标->RGB三个值
      - RGB图像 0-255  3通道
    - 图像加载
      - 图像是通过1个二维矩阵或3个二维矩阵表示
        - imread()
        - imshow()
        - imsave()
      - 矩阵的值就是像素点(特征值)
      - 图像形状(H W C)
  - CNN介绍
    - 概念
      - 包含卷积层和池化层的神经网络计算模型
      - Convolutional neural network
    - 组成
      - 输入层
        - 图像
        - 视频
        - 音频
          - 频谱图...
      - 卷积层
        - 提取图像特征图
      - 激励层
        - 激活函数
      - 池化层
        - 降低卷积层特征图维度
      - 全连接层
        - 数据是二维数据集
        - 一张图像是1个一维向量, 有多少个值就是有多少个像素点(C*H*W)
    - 应用
      - 图像分类
      - 目标检测
      - 面部解锁
      - 自动驾驶
  - 卷积层
    - 作用
      - 提取图像特征图
    - 滤波器/卷积核
      - 带有共享参数的神经元
      - 有多少滤波器就是有多少个神经元
    - 卷积基本计算
      - 根据卷积核大小对特征图进行点乘运算
      - 点乘运算结果=新特征图1个特征值
      - 特征图的窗口矩阵=卷积核大小
    - padding
      - 特征图周围补0
      - 作用
        - 防止边缘信息丢失(计算多次)
        - 新特征图和原特征图形状保持一致
    - stride
      - 窗口矩阵移动步长
      - 作用
        - 降维
        - 提高感受视野
    - 多通道卷积计算
      - RGB图像有3个通道, 卷积核也有3个通道
      - 每个通道进行点乘运算, 然后3个点乘结果求和=新特征图1个特征值(像素点)
      - 1个二维特征图
    - 多通道多卷积核计算
      - 多个卷积核就是多个神经元
      - 每个神经元提取1个二维特征图
      - 有多少个神经元就会提取多少个二维特征图
    - 特征图大小计算
      - N = floor((W-F+2P)/S + 1)
      - W:原特征图大小
      - F:卷积核大小
      - P:补零圈数
      - S:步长
    - API
      - conv = nn.Conv2d(in_channels, out_channels, kernel_size, stride, padding)
      - in_channels
        - 输入图像的通道数
      - out_channels
        - 卷积核/神经元个数
        - 有多少个神经元就会提取多少个二维特征图
      - kernel_size
        - 卷积核形状
        - 滑动窗口大小
      - stride
        - 步长, 默认1
      - padding
        - 填充圈数, 默认0
  - 池化层
    - 作用
      - 降维, 只在H,W维度上降维
      - 没有神经元参与
    - 池化计算
      - 最大池化
        - 提取窗口范围内的最大特征值
      - 平均池化
        - 提取窗口范围内的平均特征值
    - 多通道池化计算
      - 不改变通道数
      - 只在H,W维度上池化
    - API
      - nn.MaxPool2d(kernel_size=2, stride=2, padding=1)
      - nn.AvgPool2d(kernel_size=2, stride=1, padding=0)
  - 图像分类案例
    - 加载数据集 -> CIFAR10数据集
    - 构建神经网络分类模型
      - __init__方法
        - 调用父类init方法
        - 卷积层
          - nn.Conv2d(in_channels=3, out_channels=6, kernel_size=3)
          - in_channels
            - 初始卷积层参数值=图像的通道数
        - 池化层
          - nn.MaxPool2d(kernel_size=2, stride=2)
        - 全连接层
          - 隐藏层
            - nn.Linear(in_features=16 * 6 * 6, out_features=120)
            - 第1层隐藏层接收的样本特征数=池化后一张图像C*H*W的结果
          - 输出层
            - nn.Linear(in_features=84, out_features=10)
            - out_features=分类数量
        - dropout层
          - nn.Dropout(p=0.5)
      - forward方法
        - 卷积计算
          - x=self.conv1(x)
        - 激活值计算
          - x=torch.relu(x)
        - 池化计算
          - x=self.pool1(x)
        - 线性计算
          - 先修改池化计算x的形状(batch_size, C, H, W)->(batch_size, C*H*W)
          - x=self.linear1(x)
        - 激活值计算
          - x=self.pool1(x)
        - 输出层计算
          - x=self.linear1(x)
          - 多分类在损失函数中进行softmax激活计算
