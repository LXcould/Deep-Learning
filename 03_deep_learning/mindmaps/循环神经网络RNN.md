- 循环神经网络RNN
  - 介绍
    - 概念
      - 处理序列数据的一种神经网络计算模型
      - 序列数据
        - 数据是根据时间步生成
        - 前后数据有关联关系
        - 文本数据
    - 应用
      - 生成式AI 大模型
      - 机器翻译
      - 语音识别
      - NLP
      - ...
  - 词嵌入层
    - 作用
      - 将词用向量表示, 输入到RNN层
      - 低维稠密向量
      - 保持上下文语义
    - 用法
      - 将文本通过jieba分词等模块进行分词
      - 根据每个词下标值转换成向量
      - 向量->下标->词
    - API
      - embed = nn.Embedding(num_embeddings=len(words), embedding_dim=8)
      - num_embeddings
        - 词数量
      - embedding_dim
        - 向量维度
  - RNN循环层
    - 作用
      - 具有记忆功能的网络
      - 处理序列数据
    - 原理
      - 上一步的隐藏状态h0和输入x词向量经过循环网络输出当前步的隐藏状态和预测结果
      - 预测结果最终进入全连接神经网络, 输出词汇表中N个词的概率, 概率最大的词就是最终预测的y值
      - h1=激活函数((wh0+b)+(wx+b))
      - 循环层预测结果=wh1+b
    - API
      - 创建RNN对象
        - rnn = nn.RNN(input_size, hidden_size，num_layers)
        - input_size：输入数据的维度，一般设为词向量的维度
        - hidden_size：隐藏层h的维度，也是当前层神经元的输出维度
        - num_layers: 隐藏层h的层数，默认为1
      - 调用RNN对象
        - output, hn = RNN(x, h0)
        - x/output的表示形式为 (句子的长度，batch的大小，词向量的维度)
        - h0/hn的表示形式为 (隐藏层的层数，batch的大小，隐藏层h的维度])
        - rnn层的预测结果词向量维度=隐藏层的维度
  - 文本生成案例
    - 需求
      - 根据输入的某个词,生成由n个词组成的句子
      - 实际上是一个多分类问题, 词汇表中有多少词就是多少分类问题
      - 全连接输出层输出每个词的概率,最大概率的词就是当前的预测词,依次类推一直预测出50个词
    - 构建词汇表
      - 词汇表  唯一词的列表
      - 歌词文本用词汇表中下标索引表示列表
      - 词汇表中词的数量
      - 词和下标索引的映射字典
    - 构建数据集
      - x是歌词文本中n个词组成的所有句子
        - 我爱你
          - x1
        - ,爱你
          - x2
        - 爱你中国
        - 你中国,
        - 中国,亲爱
        - ,亲爱的
      - y是x+1(x中词后一个)
        - ,爱你
          - y1
        - 爱你中国
          - y2
        - 你中国,
        - 中国,亲爱
        - ,亲爱的
      - 1个样本中x1是由n个词向量组成的特征值,y1是由n个词向量组成的目标列
    - 构建神经网络分类模型
      - __init__
        - 调用父类init方法
        - 词嵌入层
        - RNN层
        - 全连接层
      - forward
        - 每个batch中词转换成词向量
        - 调用rnn层输入当前的预测结果和当前时间步的隐藏状态值
        - rnn层预测结果经过全连接输出层得到词汇表中N个词的分值
      - init_hidden
        - 初始化第1个时间步的隐藏状态(全0)
    - 模型训练
      - 创建词汇表
      - 创建数据集
      - 创建数据加载器
      - 创建模型对象
      - 创建交叉熵损失函数
      - 创建优化器对象
      - 循环遍历训练epoch
      - 循环遍历数据加载
        - 循环遍历时会自动调用自定义数据集对象
        - 初始化隐藏状态
        - 模型预测
          - 预测y值
          - 当前时间步的隐藏状态
        - 计算损失值
        - 梯度清零
        - 梯度计算
        - 参数更新
      - 模型保存
    - 模型预测
      - 传入起始词
      - 创建模型对象
      - 加载训练模型的参数字典
      - 初始化隐藏状态值
      - 将起始词转换成词下标索引
      - 将起始词保存到列表中
      - 循环遍历句子需要的词数量
        - 模型预测, 获取预测分值
        - 获取最大预测分值的下标索引
        - 将预测词的下标索引保存到起始词下标列表中
      - 根据词对应下标的字典将词下标列表转换成词连接成一句话进行输出,得到最终预测的句子
