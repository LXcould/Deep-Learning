- 人工神经网络基础
  - 神经网络介绍
    - 什么是神经网络模型
      - 深度学习计算模型, 仿生生物学神经元构造
    - 如何构造神经网络模型
      - 由多个神经元构成
        - 根据w和b进行加权求和 z=wx+b(线性因素)
        - 根据激活函数进行激活值计算(引入非线性因素)
      - 输入层
        - 输入样本初始特征值 x, 一层
      - 隐藏层
        - 提取复杂的特征值, 多层
        - 每一层有多少个神经元, 提取到多少复杂的特征
      - 输出层
        - 输出模型预测结果
    - 激活函数
      - 作用
        - 引入非线性因素
      - sigmoid
        - 激活值范围[0, 1], 没有负信号
        - 激活导数范围[0, 0.25]
          - 梯度消失  0.25**5
        - 线性层输出值尽量分布在[-6,6], 激活值分布[0,1]
        - 适用于二分类输出层
      - tanh
        - 激活值范围[-1, 1], 正负信号都存在
        - 激活导数范围[0, 1]
          - 梯度消失速度慢
          - 模型收敛更好
        - 线性层输出值尽量分布在[-3,3], 激活值分布[-1,1]
        - 适用于浅层神经网络隐藏层
      - relu/leaky relu/ prelu
        - 激活值0或正x, 没有负信号
        - 激活导数0或1
          - 1: 梯度永远为1, 收敛效果更好
          - 0: 神经元死亡, 无法学习特征
        - 优先选择relu激活函数
      - softmax
        - 线性层输出值转换成概率, 概率和1
        - softmax(dim=1)
        - 适用于多分类输出层
    - 参数初始化
      - 作用
        - 防止梯度消失或梯度爆炸
        - 打破对称性
          - 模型学习的方向, 学习的特征
          - 每个神经元权重不一样, 更新时结果也不一样
      - 随机初始化
        - 均匀分布
          - 默认值是(0, 1), 可以设置为(-1/sqrt(d), 1/sqrt(d))
        - 正态分布
          - 均值为0, 标准差为1
      - 全0/1/指定值初始化
        - 测试环境中可以使用
        - 神经元学习到的特征一样, 对称性
      - kaiming初始化
        - 均匀分布
          - (-sqrt(6/输入神经元个数), sqrt(6/输入神经元个数))
        - 正态分布
          - w在(0, sqrt(2/输入神经元个数))
        - 和relu激活函数结合使用
      - xavier初始化
        - 均匀分布
          - (-sqrt(6/输入神经元个数+输出神经元个数), sqrt(6/输入神经元个数+输出神经元个数))
        - 正态分布
          - w在(0, sqrt(2/输入神经元个数+输出神经元个数))
        - 和sigmoid/tanh激活函数结合使用

  - 损失函数
    - 什么是损失函数
      - 衡量模型参数质量的函数
      - 损失函数, 代价函数, 误差函数, ...
      - 根据损失函数计算损失值, 结合反向传播算法以及梯度下降算法实现参数更新
    - 分类损失函数
      - 多分类损失函数
        - nn.CrossEntropyLoss(reduction='mean')
        - 实现softmax激活值计算+损失计算
      - 二分类损失函数
        - nn.BCELoss(reduction='mean')
    - 回归损失函数
      - MAE损失函数
        - 计算平均绝对误差
        - 导数为-1/1, 或者0点不可导用0代替
        - 对异常样本效果比较好, 不会放大异常样本误差
        - L1 正则化, 将特征权重置为0, 特征筛选
        - nn.L1Loss()
      - MSE损失函数
        - 计算均方误差
        - 任意位置都有导数, loss越大导数越大, loss越小导数越小
        - 对异常样本效果不好, 放大样本误差
        - L2正则化, 将特征权重接近0
        - nn.MSEloss()
      - Smooth L1损失函数
        - MAE(loss大)+MSE(loss小)
        - 任意位置都有导数, [-1,1]导数减小, 小于-1或大于1导数为-1或1
        - 对异常样本效果好, 不会产生梯度爆炸, 不容易跳过最低点
        - nn.SmoothL1loss()
  - 网络模型优化方法
    - 梯度下降法
      - w1 = w0 - lr*grad
        - w0是上一版模型的参数
        - lr是学习率,已知
        - grad是梯度,反向传播计算得到
      - epoch
        - 训练次数
      - iteration
        - 每次训练需要迭代多少次
        - 样本数/batch_size[+1, 不能整除需要加1]
      - batch_size
        - 每次迭代需要的样本数
      - 优化方法
        - momentum动量法
          - 当前梯度是指数移动加权平均梯度
          - St=(1-β)*Gt + β*St-1
            - 结合当前梯度*系数+历史加权平均梯度
            - 当前梯度为0,  St = 0.1*0 + 0.9*St-1 != 0
            - W0 = W1 - lr*St
        - adagrad
          - 自动调整学习率, 初始训练时学习率大, 后期训练学习率小
          - 新学习率=原始学习率 / 历史梯度平方
            - 初始训练累加梯度小, 分母小, 新的学习率大
            - 后期训练累加梯度大, 分母大, 新的学习率小
          - 适用于高维稀疏数据或文本数据
        - rmsprop
          - 自动调整学习率, 初始训练时学习率大, 后期训练学习率小
          - 新学习率=原始学习率 / 历史指数加权平均梯度平方
            - 初始训练累加梯度小, 分母小, 新的学习率大
            - 后期训练累加梯度大, 分母大, 新的学习率小
          - 避免adagrad优化方法的学习率下降过快, 导致模型震荡
          - 适用于高维稀疏数据或文本数据
        - adam
          - momentum+rmsprop
          - 优先选择
    - 反向传播算法BP
      - 根据损失值计算梯度
      - 损失值和权重参数求导过程
      - 梯度连乘
        - E/W = E/a * a/b * b/w
    - 学习率衰减策略
      - 等间隔学习率衰减
        - 训练次数(步长)相等, 学习率随着训练次数减小
        - lr = lr * gamma
        - scheduer = optim.lr_scheduler.StepLR(optimizer=optimizer, step_size=50, gamma=0.5)
        - scheduer.step()
      - 指定间隔学习率衰减
        - 自定义训练次数(步长), 学习率随着训练次数减小
        - lr = lr * gamma
        - optim.lr_scheduler.MultiStepLR(optimizer=optimizer, milestones=[50, 100, 160], gamma=0.5, last_epoch=-1)
      - 指数学习率衰减
        - 按指数减小, 前期减小快, 后期减小慢
        - lr = lr*gamma**epoch
        - optim.lr_scheduler.ExponentialLR(optimizer=optimizer, gamma=0.9)
  - 正则化
    - 什么是正则化
      - 一种解决过拟合提高模型泛化能力的策略
      - 泛化能力
        - 模型在测试样本/新样本效果要好
    - 作用
      - 训练模型时防止出现过拟合
    - 策略
      - L1正则化
      - L2正则化
        - torch.optim.SGD(weight_decay=)
      - dropout层
        - 以指定p概率让神经元随机失活
        - 每批次训练时失活的神经元不是固定, 得到不同的子网络, 防止预测结果过分依赖某些神经元
        - 注意点
          - 在激活层后使用
          - 未失活的神经元输出除以(1-p)
          - dropout在测试集上不生效
        - 模型状态切换
          - 训练模式 model.train()
          - 测试模式 model.eval()
        - API
          - nn.Dropout(p=0.4)
      - BN批量归一化层
        - 对线性结果进行标准化处理
          - 根据每批样本的均值和标准差计算标准化的值
        - 作用
          - 正则化
            - 不同批次样本的均值和标准差不一样, 有可能会引入噪声样本, 降低训练模型效果
          - 加快模型收敛速度
            - 数据分布均匀, 落入不同激活函数要求的范围内
            - sigmoid/tanh激活函数->数据分布在0附近,导数最大
        - 注意点
          - 在激活层前使用(卷积层后/线性层后)
          - 多数在计算机视觉领域使用
          - 可以引入γ和β可学习参数, 不同层的样本分布在不同范围内(不同层使用的激活函数不同); 可以补回标准化丢失的信号
        - API
          - nn.BatchNorm1d(num_features=4)
          - nn.BatchNorm2d(num_features=4)
