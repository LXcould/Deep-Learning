## 第一级：填空（把 `______` 补上，跑通为止）

### 1. 最简单的函数

```python
______ add(a, b):
    ______ a + b

print(add(3, 5))          # 8
```

### 2. 返回值的位置

```python
def average(nums):
    total = 0
    for n in nums:
        total += n
    ______ total / len(nums)

print(average([80, 90, 100]))    # 90.0
```

### 3. 默认参数

```python
def greet(name, ______="你好"):
    print(f"{______}, {name}")

greet("小明")                # 你好, 小明
greet("小红", "早上好")        # 早上好, 小红
```

### 4. 返回多个值

```python
def min_max(nums):
    ______ min(nums), max(nums)

low, high = min_max([3, 1, 9])
print(low, high)           # 1 9
```

### 5. 不定长参数

```python
def total(*______):
    s = 0
    for n in ______:
        s += n
    return s

print(total(1, 2, 3))       # 6
```

### 6. 不定长关键字参数

```python
def show(**info):
    for k, v in info.______():
        print(f"{k}: {v}")

show(name="小明", age=20)
# name: 小明
# age: 20
```

### 7. lambda

```python
double = ______ x: x * 2
print(double(5))            # 10
```

### 8. 作用域（在函数里修改外面的变量）

```python
count = 0

def add_one():
    ______ count
    count += 1

add_one()
print(count)                # 1
```

## 第二级：改写（在能跑的代码上改，这一级最重要）

**做法**：先把原始代码跑通，然后按新需求改。你改动的只有几行，但经历了完整的"理解 → 定位 → 修改 → 验证"流程。

### 9. 原始代码：算平均分

```python
scores = [88, 92, 75, 60]
total = 0
for s in scores:
    total += s
print(total / len(scores))
```

**改成**：包装成函数 `average(scores)`，返回平均值。

### 10. 接着第 9 题

**改成**：再加一个函数 `pass_rate(scores)`，返回及格率（百分比）。

### 11. 原始代码：统计某个字符出现的次数

```python
text = "banana"
target = "a"
count = 0
for ch in text:
    if ch == target:
        count += 1
print(count)
```

**改成**：包装成函数 `count_char(text, target)`，返回次数。

### 12. 原始代码：判断成绩等级

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

**改成**：包装成函数 `grade(score)`，**返回**等级字符串，不打印。

### 13. 接着第 12 题

**改成**：写一个函数 `grade_all(scores)`，接收一串成绩，返回等级列表。
（提示：在函数里用列表推导式，或者循环里 `append`）

### 14. 用 lambda 排序

```python
students = [{"name": "小明", "score": 88},
            {"name": "小红", "score": 95}]
```

**改成**：按分数从高到低排序并打印。

## 第三级：从零写（关掉所有资料，空文件开始）

**写不出来就先写中文注释**，把步骤列出来，再一行一行翻译成代码。

### 15. 判断素数

写函数 `is_prime(n)`，返回 `True` 或 `False`。
（提示：从 2 循环到 n-1，如果能整除就不是素数）

### 16. 反转字符串

写函数 `reverse_str(s)`，返回反转后的字符串，**不许用 `s[::-1]`**。
（提示：循环遍历原字符串，把每个字符拼到新字符串的前面）

### 17. 统计单词

写函数 `count_words(text)`，返回一个字典，键是单词，值是出现次数。
（提示：`text.split()` 切词，字典统计的方法你在数据容器练过）

### 18. 筛选及格

写函数 `filter_passed(scores)`，返回所有及格（>=60）的分数组成的列表。

### 19. 任意个数的最大值

写函数 `max_of(*nums)`，接收任意个参数，返回其中最大的值，**不许用 `max()`**。

**15.**

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, n):
        if n % i == 0:
            return False
    return True
```

**16.**

```python
def reverse_str(s):
    result = ""
    for ch in s:
        result = ch + result
    return result
```

**17.**

```python
def count_words(text):
    counts = {}
    for w in text.split():
        counts[w] = counts.get(w, 0) + 1
    return counts
```

**18.**

```python
def filter_passed(scores):
    return [s for s in scores if s >= 60]
```

**19.**

```python
def max_of(*nums):
    result = nums[0]
    for n in nums:
        if n > result:
            result = n
    return result
```

## 一句话记住写函数的顺序

**先把任务写成普通代码，跑通了，再包成函数。**

包的时候只改两处：

- 外面进来的数据 → 变成**参数**
- 要输出给外面的结果 → 变成 **return**

不用凭空想出一个函数，把已有代码搬进去就行。
