> 本集讲"解包"：把一个容器里的元素一次性分给多个变量。

## 知识点

### 1. 基本解包

```python
a, b, c = [1, 2, 3]
print(a, b, c)      # 1 2 3

# 变量个数必须和元素个数一致，否则报错
# a, b = [1, 2, 3]   # 报错
```

### 2. 用星号接收剩余元素

```python
first, *rest = [1, 2, 3, 4]
print(first)    # 1
print(rest)     # [2, 3, 4]

*head, last = [1, 2, 3, 4]
print(head)     # [1, 2, 3]
print(last)     # 4
```

### 3. 交换变量（解包的经典用法）

```python
x, y = 10, 20
x, y = y, x
print(x, y)     # 20 10
```

右边 `y, x` 先组成一个元组 `(20, 10)`，再解包给左边。不用中间变量。

### 4. 遍历时的解包

```python
points = [(1, 2), (3, 4), (5, 6)]

for x, y in points:
    print(f"x={x}, y={y}")
```

### 5. 函数多返回值本质就是解包

```python
def get_min_max(nums):
    return min(nums), max(nums)      # 实际返回的是元组

low, high = get_min_max([3, 1, 9, 5])
print(low, high)      # 1 9
```

## 本节案例

```python
students = [("小明", 88), ("小红", 95), ("小刚", 72)]

# 找出最高分的学生
top_name, top_score = students[0]
for name, score in students:
    if score > top_score:
        top_name, top_score = name, score

print(f"最高分：{top_name}，{top_score} 分")

# 只关心第一个和其余
first, *others = students
print(f"第一个：{first}")
print(f"其余：{others}")
```
