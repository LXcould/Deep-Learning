## 知识点

### 1. 基础语法

```python
[表达式 for 变量 in 可迭代对象]
```

```python
nums = [1, 2, 3, 4, 5]
squares = [x * x for x in nums]
print(squares)      # [1, 4, 9, 16, 25]
```

等价于：

```python
squares = []
for x in nums:
    squares.append(x * x)
```

### 2. 带条件过滤

```python
[x for x in range(10) if x % 2 == 0]     # [0, 2, 4, 6, 8]
[x for x in nums if x > 3]               # [4, 5]
```

### 3. 带 if-else 的表达式

```python
["及格" if x >= 60 else "不及格" for x in [88, 45, 72]]
# ['及格', '不及格', '及格']
```

⚠️ 注意位置：`if` 在 `for` 后面是**过滤**，`if...else` 在 `for` 前面是**加工**。

### 4. 嵌套推导式与字典推导式

```python
[[i * j for j in range(1, 4)] for i in range(1, 4)]
# [[1, 2, 3], [2, 4, 6], [3, 6, 9]]

{x: x * x for x in range(4)}    # {0: 0, 1: 1, 2: 4, 3: 9}
```

## 本节案例

```python
scores = [88, 45, 72, 95, 30, 66]

# 1. 只保留及格分数
passed = [s for s in scores if s >= 60]
print(passed)          # [88, 72, 95, 66]

# 2. 全部加 5 分（不超 100）
curved = [min(s + 5, 100) for s in scores]
print(curved)

# 3. 打上标签
labels = ["及格" if s >= 60 else "不及格" for s in scores]
print(labels)

# 4. 生成 1-20 里 3 的倍数
print([x for x in range(1, 21) if x % 3 == 0])
```
