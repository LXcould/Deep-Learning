## 知识点

### 查找

```python
a = [10, 20, 30, 20]

a.index(20)     # 1        查找元素第一次出现的下标，找不到会报错
a.count(20)     # 2        统计出现次数
len(a)          # 4        列表长度（这是内置函数，不是方法）
30 in a         # True     判断元素是否存在
```

### 增加

```python
a = [1, 2]

a.append(3)         # [1, 2, 3]        末尾追加一个元素
a.extend([4, 5])    # [1, 2, 3, 4, 5]  末尾追加一整串
a.insert(0, 0)      # [0, 1, 2, 3, 4, 5]   在下标 0 处插入
```

⚠️ `append([4,5])` 会把整个列表当成一个元素塞进去，`extend` 才是拆开加。这两个别搞混。

### 修改

```python
a = [1, 2, 3]
a[0] = 100       # [100, 2, 3]

a[0:2] = [7, 8]  # [7, 8, 3]   切片赋值可以一次改多个
```

### 删除

```python
a = [1, 2, 3, 2]

a.remove(2)      # [1, 3, 2]   删除第一个值为 2 的元素
a.pop()          # 删除并返回最后一个，a 变 [1, 3]
a.pop(0)         # 删除并返回下标 0 的元素
del a[0]         # 直接删除下标 0 的元素
a.clear()        # 清空
```

### 排序与反转

```python
a = [3, 1, 2]

a.sort()                 # a 变成 [1, 2, 3]，就地修改
a.sort(reverse=True)     # [3, 2, 1]   降序
a.reverse()              # 就地反转

b = sorted(a)            # 返回新列表，a 不变
```

⚠️ `sort()` 是就地修改，返回值是 `None`。写 `a = a.sort()` 会让 a 变成 `None`。

### 复制

```python
a = [1, 2, 3]
b = a              # 只是起别名，改 b 会连 a 一起改
c = a.copy()       # 真正的复制，互不影响
d = a[:]           # 切片写法，同样能复制
```

## 本节案例

```python
scores = [88, 92, 75, 92, 60]

print("原列表：", scores)
print("人数：", len(scores))
print("92 第一次出现在下标：", scores.index(92))
print("92 出现次数：", scores.count(92))

scores.append(100)
print("追加后：", scores)

scores.remove(60)
print("删除 60 后：", scores)

scores.sort(reverse=True)
print("降序后：", scores)
print("最高分：", scores[0])
```
