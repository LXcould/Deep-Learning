## 知识点

**什么是数据容器**：一个变量里能装多个数据的"容器"。

```python
name = "小明"                  # 一个变量装一个数据
scores = [90, 85, 77, 92]      # 一个变量装多个数据，这就是容器
```

**Python 的五种数据容器**：

| 容器 | 写法 | 可变 | 有序 | 允许重复 | 一句话 |
|---|---|---|---|---|---|
| 列表 list | `[1, 2, 3]` | 是 | 是 | 是 | 最常用，什么都能装 |
| 元组 tuple | `(1, 2, 3)` | 否 | 是 | 是 | 不可变，改了会报错 |
| 字符串 str | `"abc"` | 否 | 是 | 是 | 本质是字符序列 |
| 集合 set | `{1, 2, 3}` | 是 | 否 | 否 | 自动去重，做交并差 |
| 字典 dict | `{"a": 1}` | 是 | 是 | 键唯一 | 键值对，按 key 查 |

**选型口诀**：

- 要按顺序存一堆 → 列表
- 要按名字查 → 字典
- 要去重 → 集合
- 数据不允许被改 → 元组
