## 知识点

### 1. 列表的特点

**有序、可变、允许重复、什么类型都能装。** 用中括号 `[]` 定义，元素之间用逗号分隔。

```python
nums = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]   # 可以混装不同类型
empty = []                          # 空列表
nums2 = list("abc")                 # ['a', 'b', 'c']
```

### 2. 下标索引

列表里每个元素都有一个编号（下标），**正向下标从 0 开始，反向下标从 -1 开始**。

```python
nums = [10, 20, 30, 40, 50]
#        0   1   2   3   4
#       -5  -4  -3  -2  -1

print(nums[0])     # 10
print(nums[2])     # 30
print(nums[-1])    # 50   最后一个
print(nums[-2])    # 40   倒数第二个

# print(nums[10])  # 报错 IndexError，下标越界
```

### 3. 嵌套列表

列表里可以再放列表，取值时**从左往右一层一层剥**。

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

print(matrix[0])        # [1, 2, 3]
print(matrix[1][2])     # 6
print(matrix[-1][-1])   # 9
```

### 4. 遍历

```python
nums = [10, 20, 30]

for n in nums:                # 直接取元素
    print(n)

for i, n in enumerate(nums):  # 同时拿下标和元素
    print(i, n)
```

## 本节案例

**案例：取出指定位置的数据**

```python
students = ["小明", "小红", "小刚", "小美"]

print(f"第一个学生是：{students[0]}")
print(f"最后一个学生是：{students[-1]}")
print(f"一共 {len(students)} 个学生")

for i, name in enumerate(students):
    print(f"第 {i + 1} 号：{name}")
```
