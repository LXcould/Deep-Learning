## 第二级：改写需求（在能跑的代码上改，这是最接近真实工作的训练）

**做法**：先把下面的原始代码跑通，然后按新需求改。只改需求、不动主结构。
这一级是整套训练里最重要的一级，别跳过。

### 9. 原始代码：算平均分

```python
scores = [88, 92, 75, 60, 45]
total = 0
for s in scores:
    total += s
print(f"平均分：{total / len(scores):.1f}")
```

**改成**：算及格率（>=60 的比例），输出成百分比、保留一位小数。

### 10. 接着第 9 题

**改成**：成绩不再写死在代码里，改成让用户输入 5 个成绩。
（提示：用 `input()` 配合循环，别忘 `int()`。别忘了提示语 `f"请输入第{i+1}个成绩："`）

### 11. 原始代码：找到最高分

```python
students = [{"name": "小明", "score": 88},
            {"name": "小红", "score": 95},
            {"name": "小刚", "score": 72}]

top = students[0]
for s in students:
    if s["score"] > top["score"]:
        top = s
print(f"最高分：{top['name']}，{top['score']} 分")
```

**改成**：再加一列 `"city"`，并找出分数最低的那个学生。

### 12. 原始代码：统计字符

```python
text = "hello"

for ch in text:
    counts[ch] = counts.get(ch, 0) + 1
print(counts)
```

**改成**：统计**单词**出现次数，输入换成 `"the cat sat on the mat"`。
（提示：先用 `text.split()` 把它切成单词列表）

### 13. 接着第 12 题

**改成**：不但统计次数，还要输出出现最多的那个词。
（提示：`max(字典, key=字典.get)`）

## 第三级：从零写（关掉所有资料，打开空文件）

### 17. 按分数排序

### 18. 出现次数最多的字符

**14.**

```python
def get_max(nums):
    result = nums[0]
    for n in nums:
        if n > result:
            result = n
    return result

def get_min(nums):
    result = nums[0]
    for n in nums:
        if n < result:
            result = n
    return result

nums = [5, 3, 8, 1, 9]
print(get_max(nums), get_min(nums))
```

## 每天怎么练（30–40 分钟就够）

- **第 1 天**：第一级 8 道填空全做完。
- **第 2 天**：第二级 5 道改写全做完。**这一级最重要，卡住也要做完。**
- **第 3 天**：第三级 5 道从零写。写不出来就先写中文注释再填代码。
- **第 4 天**：回头把前面所有卡住的题重做一遍，不看答案。

四天之后你会明显感觉到变化：**不是"我见过这个"，而是"我知道下一步该写什么"。**

## 一句要紧的话

写不出来的时候，**不要去看视频**，去看你写的中文注释。

把想做的事先用一句话写下来，再想"这一句话对应哪一行代码"。
写代码真正的能力就是这个——把问题拆成一句一句话，再一句一句翻译成代码。
你现在觉得难，是因为你试图一眼把整段代码想出来，没人能做到。
