## 知识点

切片就是**一次取出多个元素**，语法是：

```python
序列[开始下标 : 结束下标 : 步长]
```

**核心规则：左闭右开**——包含开始下标，不包含结束下标。

```python
nums = [10, 20, 30, 40, 50]
#        0   1   2   3   4

nums[1:3]     # [20, 30]        含 1，不含 3，所以是两个元素
nums[:3]      # [10, 20, 30]    省略开始 = 从头开始
nums[3:]      # [40, 50]        省略结束 = 取到结尾
nums[:]       # 整个列表
nums[1:4]     # [20, 30, 40]
```

### 负数下标切片

```python
nums[-3:]      # [30, 40, 50]    最后三个
nums[:-2]      # [10, 20, 30]    去掉最后两个
nums[-4:-1]    # [20, 30, 40]
```

### 步长

```python
nums[::2]      # [10, 30, 50]    每隔一个取
nums[1::2]     # [20, 40]
nums[::-1]     # [50, 40, 30, 20, 10]   步长为负 = 反转
```

### 切片得到的是新列表

```python
a = [1, 2, 3, 4]
b = a[1:3]      # [2, 3]
print(a)        # [1, 2, 3, 4]    a 没变

c = a[:]        # 复制一份，和 a 互不影响
```

## 本节案例

```python
nums = [10, 20, 30, 40, 50, 60, 70]

print("前三个：", nums[:3])
print("后三个：", nums[-3:])
print("中间三个：", nums[2:5])
print("偶数位：", nums[::2])
print("反转：", nums[::-1])
```

3. 用一行代码把任意列表反转。
4. 思考：`a[1:3]` 和 `a[3:1]` 分别得到什么？为什么第二个是空列表？
