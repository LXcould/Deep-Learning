## 案例目标

用列表管理一组学生成绩，完成：录入、统计、查找、修改、排序。

## 思路分析

1. 先用一个列表把数据存起来
2. 遍历列表求和，算平均分
3. 用 `max()` / `min()` 找最高最低分
4. 用 `count()` 数不及格人数
5. 用 `sort()` 排序输出

## 参考代码

```python
scores = [88, 92, 75, 60, 92, 45, 78]

# 1. 基本信息
print(f"共 {len(scores)} 名学生")

# 2. 总分与平均分
total = 0
for s in scores:
    total += s
print(f"总分：{total}，平均分：{total / len(scores):.2f}")

# 3. 最高分与最低分
print(f"最高分：{max(scores)}，最低分：{min(scores)}")

# 4. 统计不及格（<60）人数
fail = 0
for s in scores:
    if s < 60:
        fail += 1
print(f"不及格人数：{fail}")

# 5. 排序后输出
sorted_scores = sorted(scores, reverse=True)
print("成绩排行榜：")
for i, s in enumerate(sorted_scores, start=1):
    print(f"第 {i} 名：{s}")
```

## 关键点回顾

- `len()` 求长度，`sum()` 求和（也可以用循环累加）
- `max()` / `min()` 直接取最大最小
- `sorted()` 返回新列表，不影响原数据；`sort()` 就地修改
- `f"{x:.2f}"` 保留两位小数
- `enumerate(列表, start=1)` 让编号从 1 开始
